# Chrome Web Store listing draft

## Name
ChatFolio - AI Chat to PDF

## Short description
Export ChatGPT, Claude, and Gemini conversations to readable PDF files.

## Detailed description
ChatFolio exports supported AI conversations to PDF directly from the browser.

It supports ChatGPT, Claude, and Gemini and is designed for both short and long conversations. The extension scans the conversation, keeps user and assistant messages visually separated, preserves common formatting such as headings, lists, tables, code blocks, links, images, and detected attachments, and opens the result in Chrome's print flow so it can be saved as a PDF.

Features include multilingual right-to-left and left-to-right layout, Comfortable and Compact reading density, optional message numbers and images, Light/Graphite/Dark extension themes, stop controls for long scans, and local preference storage.

ChatFolio processes conversation content in the browser. It does not send conversation text to a ChatFolio-controlled server.

Provider interfaces can change over time, so extraction may occasionally be affected until the extension is updated.

## Privacy summary
- Conversation content is processed locally in the browser.
- No ChatFolio analytics or advertising service is used.
- Local extension settings are stored in Chrome storage.
- Provider-hosted images may be fetched when image embedding is enabled.
